# SEYMEN Terminal Operations Implementation Plan

- Nakliyeci Portalı: canlı durum, onaylı araç havuzu, belge geçerliliği, talep rezervasyonu, tarih kısıtı, rapor.
- Pregate: talep sorgu, evrak ön izleme/onay-red, saha kontrolü, ADR+kart, işlemdeki araçlar, rapor.
- Ürün & ADR: ürün listesi, tank kodu sırası, uygunluk kontrolü, işaretleme ve KKD.
