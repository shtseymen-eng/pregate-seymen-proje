# SEYMEN Terminal Operasyon Yönetim Sistemi

Bu depo, **Nakliyeci Portalı + Pregate Operasyonları + ADR/Uygunluk + Saha Kontrol + Kart + Operasyon + Kantar + Raporlama** modüllerini tek bir interaktif satış demosunda birleştirir.

## Çalıştırma
`index.html` dosyasını tarayıcıda açın. Build işlemi gerekmez.

## Ana özellikler
- Mavi sinematik açılış ekranı
- Hover ile büyüyen yuvarlak modüller
- Seçilen modüle doğrudan giriş
- Açılır/kapanır sol menü
- Beyaz, kurumsal çalışma ekranları
- Firma / araç / sürücü / evrak kayıtları
- Yükleme talebi
- Pregate onayı
- Saha kontrolü
- Kart atama
- Operasyon -> kantar -> tamamlanma akışı
- ADR ürün/tank kodu kontrol demosu
- Raporlama
- LocalStorage ile tarayıcıda demo veri kalıcılığı

## Not
Bu çalışma üretim backend'i değildir. Satış ve entegrasyon demosudur. Kurumsal canlı kullanım için sunucu, veritabanı, kimlik doğrulama, API, güvenlik ve entegrasyon katmanları ayrıca geliştirilmelidir.
